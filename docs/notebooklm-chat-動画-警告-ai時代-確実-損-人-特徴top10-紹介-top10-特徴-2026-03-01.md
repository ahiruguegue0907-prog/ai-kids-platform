# 動画「【警告】AI時代に確実に損する人の特徴TOP10」で紹介されているTOP10の特徴と、それぞれ...

导出时间: 2026/3/1 13:03:55

---

動画「【警告】AI時代に確実に損する人の特徴TOP10」で紹介されているTOP10の特徴と、それぞれのポイントは以下の通りです。

**第10位：自分で考える人**

**ポイント**: 自分の頭だけで考えてからAIに指示を出すと、無意識のうちに**AIの実力や可能性を制限**してしまいます\[1\]。まずはAIに「最善の案を提案して」「必要な情報を質問して」と働きかけ、AIが出した複数の選択肢の中から自分で判断する方が、自分では思いつかなかったような良案を引き出すことができます\[2\]\[3\]。

**第9位：転職したことがない人**

**ポイント**: 何年も同じやり方で仕事をしていると、仕事の変化に対する抵抗感が生まれます\[4\]。AI時代は仕事で求められるスキルややり方が激変するため、**変化に適応するスピード**が問われます\[4\]。まずは自分の提出物をAIにレビューさせるなどの小さな変化から始め、環境に限界を感じる場合は転職して一歩踏み出すことも重要です\[4\]\[5\]。

**第8位：完璧主義な人**

**ポイント**: 情報が足りないからと頭の中だけで完璧を求めると、動けないまま時間だけが過ぎてしまいます\[6\]。まずは不完全な情報でも**AIに「叩き台」を作らせる**ことで、足りない情報や改善点が具体的に見え、圧倒的なスピードで仕事を前に進めることができます\[6\]\[7\]。

**第7位：完璧主義じゃない人**

**ポイント**: AIを使えば誰でも数分で「80点の成果物」を作れるようになりますが、そこで満足して手放してしまうと「自分でAIで作ったほうが早い」と上司に思われてしまいます\[7\]\[8\]。面倒でもAIのレビューを何度も繰り返し、**100点に近づけるよう最後まで品質を詰め切る**人こそが重宝されます\[8\]\[9\]。

**第6位：合理的な人**

**ポイント**: 論理的に正しい答えを導く「合理性」においては、もはや人間はAIに勝てないため、合理性だけで勝負する人はAIに代替されます\[10\]。人間に求められるのは、他の人にはない独自の味方や判断基準である\*\*「偏り」\*\*です\[10\]\[11\]。好きなことに深くのめり込んだり、人が嫌がることをあえて経験したりして、自分だけの偏りを育てることが重要です\[11\]。

**第5位：文句を言わない人**

**ポイント**: 日々の文句や不満は、解決が必要な問題を見つける「原石」であり、**仕事の成果を生む最高の材料**になります\[12\]。不満をただ飲み込んだりSNSに愚痴ったりするのではなく、AIの音声対話などに吐き出し、AIと一緒に問題を深掘りして解決策（仕組み化やチェックリストの作成など）を提案させることで、大きな評価に繋がります\[12\]。

**第4位：愛嬌がない人**

**ポイント**: AIによって仕事のスキルの差が縮まる時代では、意識の矢印を「自分」ではなく「相手」に向けられる\*\*「愛嬌」の価値が急上昇\*\*します\[15\]。自分の失敗をAIと磨いて場を和ませる鉄板ネタにしたり、AIツールで相手との会話を記録して次に活かしたり、自分の会話動画をAIに分析させて改善するといった行動の積み重ねが愛嬌を育てます\[16\]\[17\]。

**第3位：サボらない人**

**ポイント**: 真面目にコツコツ手作業を続ける人は評価されず、\*\*「いかにサボって（AIで効率化して）成果を出すか」\*\*を考えられる人が得をします\[18\]\[19\]。AIと会話して自分の業務の「サボりどころ（無駄）」を発見し、議事録作成や情報収集などをAIツールで自動化・仕組み化する視点を常に持つことが求められます\[19\]。

**第2位：国語が苦手な人**

**ポイント**: AIへの指示（プロンプト）に曖昧な部分や解釈の余地が残っていると、正確な意図が伝わらず、見当違いな回答が返ってきてしまいます\[19\]。AIに「より良いアウトプットを出すために聞きたいことを質問して」と頼むなどして、言葉を具体化し、\*\*解釈の余地をなくす厳密な言語化能力（国語力）\*\*が必須になります\[22\]\[23\]。

**第1位：エンジニアじゃない人**

**ポイント**: ここで言うエンジニア的思考とは、表面的なテクニックを暗記するのではなく、AIの仕組みやツールの設計思想など\*\*「物事を根本から理解しようとする姿勢」\*\*のことです\[23\]\[24\]。AIの進化が早く、小手先のコツがすぐに通用しなくなる時代において、根本の仕組みを理解している人だけが、変化に振り回されずに新しいツールを使いこなすことができます\[24\]\[25\]。
