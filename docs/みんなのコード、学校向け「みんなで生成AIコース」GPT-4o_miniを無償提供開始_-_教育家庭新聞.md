# みんなのコード、学校向け「みんなで生成AIコース」GPT-4o miniを無償提供開始

2024年10月27日

**NPO法人みんなのコードは、学校向け生成AIツール「みんなで生成AIコース」において、GPT-4o miniの無償提供を開始した。**

**今回、利用可能になるGPT-4o miniは、これまで提供していたGPT-3.5より新しいモデルである「GPT-4o」を軽量化させたモデルで、MMLUベンチマークでの正答率が69.8%から82%へと向上し、より複雑な指示のプロンプトにも応答する。また、これまでよりも長い会話を続ける事が可能となり、入力トークン数が4千から12万8千に増加している。** 

■ 2024年度「みんなで生成AIプロジェクト」参加校を募集

同法人では、2024年度「みんなで生成AIプロジェクト」の参加校を募集している。全国の希望するすべての小中高で「みんなで生成AIコース」を無償で利用できる。参加校は、生成AIの基礎から「みんなで生成AIコース」を使った授業実践例まで学習できるオンデマンド動画を視聴できる。

利用に際しては、アンケートへの協力や授業の実施内容の報告が必要となる。無償提供期間は来年3月31日まで。
