## ピースAIなら…

ピースAIなら、先生の負担を抑えながら、子どもたちの主体的な学びを応援します。AIが不適切な情報を文脈ベースとキーワードで二重にブロックし、安全性を担保。画像入力や画像生成が可能な高性能AI環境や、ふりがな＆簡単解説機能で、小学生にも直感的に使える安心設計です。

verified_user 二重構造の安全フィルタリング

psychology 学びを支える支援者として振る舞う、簡単設計AIアシスタント

dashboard_customize 簡単管理でパソコン初心者でも使えます 

## ピースAIの主な特徴

security

### 安全に配慮した設計

AIが不適切コンテンツを二重でブロックし、授業時間を区切った動作で誤操作や長時間利用を防止します。

photo_camera

### 写真・画像入力で多彩なサポート

カメラや画像で問題を読み取ることで、AIがプログラミング学習や図形問題、家庭科の調理実習などをサポートします。

schedule

### 授業ごとのシステムプロンプト設定（ピースのたね）

各授業に合わせたシステムプロンプト「ピースのたね」を設定でき、時間で区切る安全設計で学びを管理します。

## よくあるご質問

dynamic_feed 利用できる対象は誰ですか？

文部科学省が設定した「学校コード」が割り当てられている学校の児童生徒や教職員にご利用いただけます。

dynamic_feed 導入までの流れを教えてください。

まずはウェビナーまたはオフライン説明会にご参加いただき、AIリテラシーの基礎テストをオンラインで受験していただきます。テスト合格後、学校単位で専用フォームからお申し込みください。

＜流れ＞

ウェビナー／説明会の受講

オンラインでAIリテラシー基礎テスト受験

学校単位で申し込みフォーム送信

管理者アカウント発行・初期設定

help_outline 利用料金はどのくらいですか？

令和7年度（2025年度）中は、すべての機能を無料でお使いいただけます。令和8年度以降の料金プランについては、年度末に改めてご案内予定です。最新情報はお問い合わせフォームまたはウェビナーでご確認ください。

devices 推奨環境は何ですか？

ブラウザベースで動作するため、以下の環境を推奨しています。

•

Windows・Chromebook・iPadいずれでもご利用可能

•

Google Chrome 最新版、Microsoft Edge 最新版、Safari 最新版を推奨

•

インターネット接続が常時安定していること

※iPadの場合、読み上げ機能がうまく動作しないことがあります。端末に標準搭載されている読み上げ機能をご利用ください。

photo_camera 画像入力はどのように使えますか？

ピースAIではカメラや画像アップロードで問題を読み取り、AIが自動でテキスト化・解析します。

チャット入力欄の「カメラ」または「画像」アイコンをタップ

カメラ撮影もしくは端末内の既存画像を選択

写真や画像と一緒に聞きたい内容を送ってください。AIがサポートします。

※写真の画質が低いと解析が難しくなる場合があります。明るい場所で撮影してください。

menu_book 管理者マニュアルはどこで入手できますか？

学校管理者アカウントでログイン後、ダッシュボードの「ヘルプ」メニューからPDF形式でダウンロードできます。また、初期セットアップ時に担当者へURLをお送りしますのでご活用ください。

manage_accounts 生徒のアカウント発行やパスワード変更について教えてください。

**発行について**

教師権限でログインした場合、クラスを作成すると同時に子どもたちのアカウントも発行されます。クラス作成時に必要なアカウント数を指定してください。発行されたアカウント一覧はCSV形式でダウンロードできます。さらに、印刷用のPDFも一人一枚になるように出力されますので、そのまま配布いただけます。

**パスワード変更について**

児童用アカウントのパスワード管理については、本人にパスワード管理の大切さを伝え、誰にも教えないようにご指導ください。

お子さんがパスワードを忘れた場合は、クラス管理画面からCSVまたはPDFを再ダウンロードしてご確認ください。どうしても変更が必要な場合は、お問い合わせフォームよりご連絡いただければ担当者が個別対応いたします。

security アカウントは安全ですか？ログイン情報はどのように管理されていますか？

児童用アカウントのパスワード管理については、本人にパスワード管理の大切さを伝え、誰にも教えないようにご指導ください。

不適切な利用（キーワードフィルタリングなど）が一定回数を超えると、アカウントが自動で凍結されます。

チャット履歴や操作履歴などのログは専用データベース上に保管され、閲覧できるのは児童本人と担当教員のみです。

lock 教師や学校管理者のパスワードはどのように管理されていますか？

教師／学校管理者のパスワードは、当方（システム運営側）でも参照できない仕様です。

教師がパスワードを忘れた場合は、学校管理者権限を持つ別の管理者がパスワード再発行を行ってください。

lock_open 保護者の同意は必要ですか？

はい。利用規約に基づき、保護者または保護者と教員の同意が必要です。

同意書のサンプルは学校管理者にメールにてお送り致します。

同意書については学校にて保管ください。

psychology ピースAIは小学生でも使えますか？

ピースAIは子どもたちでも使えるよう、アイコンをクリックすることで各種機能が呼び出せる仕組みを採用しています。また、回答内容が分かりづらかったり、漢字が読めない時には「簡単にして」ボタンがあり、ふりがなを振るとともに、補足説明が付加されます。そのため、低学年から使いやすいシステムとなっています。

support_agent サポート体制はどうなっていますか？

メールフォームにてお問い合わせを受け付けています。

visibility 個人情報やプライバシーはどのように保護されていますか？

児童の名簿情報は一切取得しておりません。

入力したテキストデータは学習用に利用せず、AIモデルにフィードバックされることはありません。

schedule 利用できる時間帯や回数制限はありますか？

教師が授業を作成する際に有効時間を設定できます。

アカウントは年度末（3月31日）を過ぎると削除されるため、翌年度以降は利用できなくなります。
