## 通学コース

教室で学ぶ

### 入会までの簡単3ステップ！

ステップ1

ゲームやアプリを作ろう！ まずは無料体験授業へ申し込み

まずは新宿、秋葉原、横浜、大阪梅田、天王寺の5教室で参加できる無料体験授業に参加ください。ゲームプログラミング（Unity・C#）、AI/機械学習（Python)、スマートフォンアプリ制作（Swift）など興味に合わせて本格的なテキストコーディングを体験できます。

[無料体験申込はこちら](https://n-codelabo.resv.jp/reserve/calendar.php) 

ステップ2

初めてでも安心！ 講師と一緒にプログラミング体験

「プログラミングって面白い！」と感じていただけるような体験授業を用意しています。実績豊富な講師のレクチャーで、初めてでも本格的な2D/3Dゲームやアプリ制作、AI/機械学習の基礎を学習することができます。 

ステップ3

無料体験授業に参加後、 1週間以内の入会で入会金無料！

[通学コースご入会フォームはこちら](https://afhb.f.msgs.jp/webapp/form/22438_afhb_29/index.do?UtmSourceFirst__c=null&UtmMediumFirst__c=null&UtmTermFirst__c=null&UtmContentFirst__c=null&UtmCampaignFirst__c=null&FirstparameterDate__c=null&UtmSourceCv__c=null&UtmMediumCv__c=null&UtmTermCv__c=null&UtmContentCv__c=null&UtmCampaignCv__c=null&_fmcs=null&yclid=null)

## 受講時間

新宿、秋葉原、横浜、大阪梅田、天王寺の5教室は全て以下の時間に開講しています。

受講日ごとに定員がありますので、申し込みはお早めにお願いします。

受講回数

クリエイティブクラス／

ジュニアクラス

**週1回**（隔週や週2〜4回も可）

大阪梅田教室は、クリエイティブクラスのみ（推奨学年：中学1年生〜 ）となります。

受講日時

水〜金曜日

1 17：15 〜 18：45

2 19：15 〜 20：45

土曜日

1 10：00 〜 11：30

2 13：00 〜 14：30

3 15：00 〜 16：30

4 17：00 〜 18：30

1回の授業は90分です。

受講時間を選んでいただき、その時間に指導を受けられます。

ご自分の受講時間以外の時間も、教室の利用、機材、書籍の利用、自習が可能です。 (一部の教室では自習利用前日の申込が必要です。)

曜日・時間によって学習できるコンテンツが異なります。詳しくは無料体験授業へお越しください。

## 料金

### 入会金

**11,000円**

※体験授業から1週間以内の入会申込で、入会金無料

### 授業料

(隔週) 14,300円/月

(週1回) 22,000円/月

(週2回) 44,000円/月

(週3回) 66,000円/月

(週4回) 88,000円/月

### パソコン利用料

(隔週) 2,200円/月

(週1回～週4回)4,400円/月

全て税込価格です。

パソコン利用料はN Code LaboのPCを利用する場合のみお支払いいただきます。ご自分で持ち込むPCをご利用の場合はかかりません｡

パソコンをお持ち込みいただく場合、授業の進行を円滑とするため、以下のスペック以上の機種をお持ち込みください。 メモリ：8GB以上 ストレージ：SSD 256GB以上。 Mac、Windowsのどちらでもかまいません。

## 入会までの流れ

まずは各教室にて実施している[「無料体験授業」](https://n-codelabo.jp/free-trial/) へお申し込みください。

無料体験授業の実施中に、保護者の方へN Code Laboのご紹介と入会手続きのご説明をいたします。

無料体験授業の終了後、入会を希望される方は体験授業でご案内した指定の申込方法でご入会のお手続きをお願いします。

※無料体験授業において、学習に集中できないなど、N Code Laboにおける学習が著しく困難と判断した場合は、入会をお断りすることがございます。ご了承ください｡

[無料体験申込はこちら](https://n-codelabo.resv.jp/reserve/calendar.php)
