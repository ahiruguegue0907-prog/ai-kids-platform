# 文部科学省、「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」を公表

2025年01月10日

2024年12月26日付けで、文部科学省が「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」を公表しました。

同省が2023年7月に公表した「初等中等教育段階における生成AIの利用に関する暫定的なガイドライン」を改訂したものです。学校現場における生成AIの適切な利活用を実現するための参考資料となるよう、生成AIの概要や基本的な考え方、場面や主体に応じて押さえておくべきポイントをまとめているとあります。
