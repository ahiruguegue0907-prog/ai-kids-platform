どちらのコースも**週1回の授業を受ける場合**の料金です。

ちなみに、通学コースは**週に最大4回まで受講**でき、その場合は月額88,000円です。ネットコースも週に1回以上受講できるのですが、最大回数と料金の記載はありませんでした。

他の教室だとオンライン教室の方が安くなるのですが、この教室は **オンライン教室の方が高い** です。

また、 **学習内容(学習コース)による料金の違いはありません**。

## ゲーム系のプログラミング教室との比較【結論：かなり高い】

結論から言うと、他のゲーム系プログラミング教室と比べて **かなり高い** です。

### 他のゲーム系教室との比較

**同じ対象年齢(小3～)向け**のゲーム系プログラミング教室を比較しました。

具体的には下記の通りで、人気ゲーム系プログラミング教室の **1年間にかかる費用**を比べています。

比べてみると、N Code Laboの **年間費用はかなり高い** ですよね。

ですが、授業回数が多いので、1回あたりの費用はそこまで高くないです。(とはいえ、これでも高い方です。平均は1回あたり5,000円前後なので。)

料金だけを見ると高額に感じてしまいますね。

### ただし、学習内容は一人ひとり違う

基本的には受講生一人ひとりにあわせて学ぶ内容が変わります。

全員が同じ内容の教材で同じように学習するタイプの教室に比べたらかなり高いですが、 **個別授業タイプの教室の中では一般的な料金**です。

これは好みでお選びください。みんなと同じで安い方がいいか、高いけどお子さんにあわせてくれる方がいいか。

### 料金に納得できたら無料体験

料金が許容範囲でしたら、 **無料体験**することをおすすめします。

無料体験をしてみて「この内容だったらこの料金も納得だな」とか「いや～これでこの料金は高いな」とかわかるはず。

先を行ってる子は何教室も体験して、自分にあった教室を選び、将来に備えています。

これからの時代、プログラミングは**必須スキル**です。ぜひ、お子さんが子供の頃からプログラミングを体験させてあげてくださいね。
